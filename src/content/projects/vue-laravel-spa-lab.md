## 為什麼做這個實驗

Side project 是驗證技術細節的低成本環境。這個專案用來確認 Vue 與 Laravel 的協作方式、API 邊界，以及本機到伺服器的部署路徑。

## 實作內容

- 建立 Vue 3 與 Laravel API 的基本協作流程。
- 使用 Docker 統一本機服務與相依環境。
- 透過 GitHub Actions 簡化部署步驟。
- 整理可重複使用的設定與文件。

## 收穫

好的骨架不一定複雜，但必須讓人能快速理解、啟動與修改。這決定了 side project 能否從一次性的 demo 演進成可持續維護的系統。
